Case studies

A selection of interfaces where accessibility shaped the architecture, not just the styling. Each project links to a short write-up and, where the client allows it, a live demo.

Live Transit Board

Northbridge Transit's departures board updates every 15 seconds. Delays and platform changes are pushed into a polite ARIA live region so screen reader users hear updates without losing their place in the page.

  • ARIA live regions
  • Vanilla JS
  • Real-time data

Accessible Checkout Flow

A checkout rebuilt around <fieldset> grouping and native validation. On submit, an error summary receives focus and lists every problem as a linked list, so keyboard and screen reader users can jump straight to the fix.

  • Forms
  • WCAG 2.2 AA
  • Error handling

Docs Command Palette

A Cmd+K search palette for a documentation site. Built with roving tabindex so arrow keys move through results the same way they would in a native menu, with the current match announced via aria-activedescendant.

  • Roving tabindex
  • Search UI
